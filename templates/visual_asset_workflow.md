# 图片占位标注规则

本规则用于主策划案撰写过程中，在需要图片辅助理解的位置留下轻量占位标注。Nodora 不生成图片、不管理图片导入，也不维护独立视觉资产计划；具体图片由用户自行插入。

## 使用原则

```text
图片占位只在图片能明显提升理解时出现，不做纯装饰。
图片占位不能替代规则说明，正文仍必须讲清楚规则、状态和边界。
图片占位不能引入未确认规则、角色、UI 终稿或美术方向。
用户后续自行把图片替换或插入到占位位置。
```

## 适合标注的位置

| 位置 | 图片类型 | 用途 |
| --- | --- | --- |
| UI 与交互需求 | UI 草图 | 帮助理解页面结构、信息层级和操作路径 |
| 系统规则 | 流程图、状态示意图 | 帮助理解条件、状态和分支 |
| 表现与反馈需求 | 氛围参考图、状态示意图 | 帮助理解反馈强度或视觉方向 |
| 方案概述 | 信息图、流程图 | 帮助快速理解整体闭环 |

## 占位格式

```text
> [图片占位：图片类型｜用途说明｜用户自行插入]
```

示例：

```text
> [图片占位：流程图｜说明任务接取、执行、结算、领取奖励的状态流转｜用户自行插入]

> [图片占位：UI 草图｜说明任务列表页的信息层级和主要操作入口｜用户自行插入]
```

## 注意事项

```text
1. 图片类型限定为：流程图、UI 草图、状态示意图、氛围参考图、信息图。
2. 不写文件路径，不写生成提示词，不声称图片已经存在。
3. 如果图片内容与主策划案文字冲突，以主策划案文字为准。
```
