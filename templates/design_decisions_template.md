# 设计决策记录模板

本文件记录已由用户确认的重要设计决策。后续策划案和岗位转译版本必须以此为依据。

## 记录规则

```text
1. 只有用户确认后的内容才能写入。
2. AI 推断不能直接写入，必须标记为待确认。
3. 如需修改已有决策，应新增变更记录，而不是直接抹除历史。
4. 后续策划案若与本文件冲突，应优先提示用户决策。
```

## 决策记录格式

```text
## DD-001 决策标题

- 决策内容：
- 适用范围：
- 决策原因：
- 不可违背点：
- 可调整点：
- 影响系统：
- 确认时间：
- 确认人：
- 来源：
- 关联待确认问题：
```

## 决策正文

## DD-001 示例：系统刷新时间

- 决策内容：示例系统采用服务器日切时间刷新。
- 适用范围：每日任务、每日奖励、每日参与次数。
- 决策原因：与项目现有日常系统保持一致，降低玩家理解成本。
- 不可违背点：不得在同一系统中混用多个刷新时间。
- 可调整点：具体日切时间可根据服务器规范调整。
- 影响系统：任务系统、奖励系统、活动系统。
- 确认时间：待填写。
- 确认人：待填写。
- 来源：示例。
- 关联待确认问题：无。
