> 来源：`docs/main_design_doc.md`、岗位阅读版、评审报告。  
> 本文件用于拆分可分配、可排期、可验收的任务，不新增未确认设计。

## 1. 任务拆分原则

- 每个任务必须有明确交付物。
- 每个任务必须能被一个主要岗位负责。
- P0 任务必须有验收条件。
- 依赖未确认的问题必须写入“待确认依赖”。
